# 📋 Project-MES 요구사항 정의서 (REQUIREMENTS)

## 1. 문서 개요

본 문서는 Project-MES의 주요 도메인별 현업 문제 상황(As-Is)을 정의하고, 이를 해결하기 위해 구현한 기능(To-Be)과 적용한 프론트엔드 기술 및 아키텍처를 정리한 문서입니다.

## 3. 요구사항 정의 및 구현 방향

Project-MES는 제조 현장의 주요 업무 흐름을 기준으로 인증 및 보안, 공정 관리, 생산 실적, 품질 검사, 설비 및 자재 관리, 인사 관리, 사내 협업의 7개 도메인으로 구성했습니다.

각 도메인의 업무 문제를 프론트엔드 기능으로 구체화하고, 다음과 같은 설계 방향을 적용했습니다.

- **데이터 관리:** TanStack Query를 활용한 서버 상태 관리 및 주기적인 데이터 갱신
- **인증 및 보안:** JWT 기반 인증, 역할별 접근 제어(RBAC), Axios Interceptor 적용
- **상태 관리:** Zustand를 활용한 전역 상태 관리 및 Derived State를 통한 파생 데이터 계산
- **사용자 경험:** 실시간 상태 표시, 임계치 기반 경고, 전역 알림 및 예외 상황 처리
- **외부 시스템 연동:** 주소 검색 및 공휴일 데이터 API 연동
- **데이터 처리:** 관리자 승인 및 백엔드 트랜잭션 연계를 통한 업무 처리

## 4. 문서 작성 목적

본 요구사항 정의서는 단순한 기능 목록이 아니라, 제조 도메인의 문제 상황을 분석하고 이를 실제 서비스 기능과 기술적 설계로 연결한 과정을 설명하기 위한 자료입니다.
