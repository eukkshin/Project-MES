# 📋 Project-MES 요구사항 및 기능 검증 명세서 (Requirements & Test Cases)

**문서 목적:** 스마트팩토리 MES(제조실행시스템) 웹 애플리케이션의 도메인별 현업 요구사항을 기능으로 구체화한 정의서와, 이에 대한 정상 흐름(Happy Path) 및 엣지/예외 상황(Edge/Exception Cases) 검증 시나리오를 통합하여 정의합니다.

## 2. 🧪 기능 검증 및 예외 상황 테스트 시나리오 (Test Cases)

구현된 핵심 기능들에 대해 정상 흐름(Happy Path)과 엣지 케이스 및 예외 상황(Edge/Exception Cases)을 검증한 **15개 항목**의 테스트 시나리오입니다.

| Test ID | 검증 도메인 | 테스트 항목명 | 테스트 시나리오 (Given - When - Then) | 예상 결과 (Expected Result) | 검증 상태 |

## 3. 💡 검증 요약 및 아키텍처 특장점
* **방어적 예외 처리:** 인증 만료, 권한 예외, 입력값 오류 등 현장 운영 중 발생할 수 있는 엣지 케이스를 철저히 방어하도록 설계되었습니다.
* **실시간 데이터 정합성:** TanStack Query의 무효화(`invalidateQueries`)와 15초 폴링 감지기를 결합하여, 백엔드 데이터와 프론트엔드 UI 간의 시차 없는 동기화를 보장합니다.
